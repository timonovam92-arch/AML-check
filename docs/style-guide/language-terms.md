## Язык и терминология

Этот раздел определяет, как мы говорим с пользователем и какие термины используем.

### Основные принципы

1.  **Простота.** Пишите короткими предложениями. Избегайте сложных конструкций и причастных оборотов, где можно обойтись без них.
2.  **Ясность.** Каждое предложение должно решать задачу пользователя. Не пишите «воду».
3.  **Уважение.** Обращайтесь к пользователю на «Вы» (с заглавной буквы) в инструкциях и руководствах. Это подчеркивает профессиональный тон.

### Термины и сокращения

1.  **Термины на английском.** Названия технологий, протоколов и форматов пишите на языке оригинала: `API`, `JSON`, `YAML`, `Git`, `CI/CD`.
2.  **Расшифровка.** При первом упоминании термина в документе давайте его краткое объяснение в скобках. Например: *«API (Application Programming Interface) — это...»*.
3.  **Единообразие.** Используйте один и тот же термин для одного и того же понятия во всех документах. Не смешивайте, например, «пользователь» и «клиент», если они не являются разными ролями.

### Глоссарий основных терминов

| Термин | Описание |
| :--- | :--- |
| **Backend** | Серверная часть приложения, которая обрабатывает данные и бизнес-логику. |
| **Build** | Процесс сборки приложения из исходного кода в исполняемые файлы. |
| **Cron** | Утилита для автоматического запуска задач по расписанию в Unix-подобных системах. |
| **Pipeline** | Автоматизированный конвейер, по которому код проходит этапы от разработки до развертывания (CI/CD). |
| **API** | Интерфейс программирования приложений; набор правил для взаимодействия программ. |
| **SDK** | Набор инструментов для разработки под конкретную платформу или сервис. |

### Чего стоит избегать

1.  **Канцеляризмов.** Вместо «произвести оплату» пишите «оплатить», вместо «осуществить вход» — «войти».
2.  **Пассивного залога.** Вместо «Кнопка была нажата пользователем» пишите «Пользователь нажал кнопку».
3.  **Лишних вводных слов.** Слова «следует отметить», «необходимо сказать» не несут смысла. Убирайте их.
4.  **Оценок и усилителей.** Слова «очень удобный», «эффективный», «идеальное решение» субъективны. Пишите факты: «Функция позволяет сделать X».
