## Правила оформления текста

Этот раздел устанавливает единые правила для визуального оформления документации.

### Заголовки

*   **Уровни.** Используйте не более 3 уровней заголовков (`#`, `##`, `###`). Это помогает сохранять структуру и не запутывать читателя.
*   **Ёмкость.** Названия заголовков должны быть короткими и отражать суть раздела.
*   **Формат.** Заголовки пишутся с заглавной буквы, без точки в конце.
*   **Пример.**
    *   `# Название документа`
    *   `## Подраздел`
    *   `### Конкретная тема`

### Списки

*   **Маркированные списки (`-`).** Используйте для перечисления элементов, когда порядок не важен.
    *   Пункты начинаются со строчной буквы.
    *   В конце каждого пункта ставится точка с запятой (`;`).
    *   Последний пункт заканчивается точкой (`.`).
*   **Нумерованные списки (`1.`).** Используйте для последовательных шагов или инструкций, где порядок критичен.
    *   Пункты начинаются с заглавной буквы.
    *   Каждый пункт заканчивается точкой (`.`).
*   **Пример.**
    *   **Маркированный список:**
        *   пункт один;
        *   пункт два;
        *   пункт три.
    *   **Нумерованный список:**
        1.  Первый шаг.
        2.  Второй шаг.
        3.  Третий шаг.

### Таблицы

*   **Когда использовать.** Для сравнения данных, описания параметров, статусов, версий — где нужна структура "ключ-значение".
*   **Оформление.** Всегда используйте заголовки таблицы (`| Заголовок | Заголовок |`).
*   **Читаемость.** Если текст в ячейке длинный, используйте `<br>` для переноса строки.
*   **Пример.**

    | Статус | Описание |
    | :--- | :--- |
    | **Новый** | Заявка создана.<br>Ожидает обработки. |
    | **Закрыт** | Заявка выполнена. |
