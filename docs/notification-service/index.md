# Сервис доставки уведомлений

- **Цель проекта:** Обеспечить надёжную и быструю отправку уведомлений по различным каналам
- **Целевая аудитория:** Разработчики, которые интегрируют этот сервис в свои приложения.  
- **Ключевые возможности:** Отправка email, SMS, push-уведомлений; управление шаблонами; получение статуса доставки.

Этот сервис предоставляет API для отправки уведомлений и проверки их статуса. 

Доступные методы:

- **POST /send/email** — отправка email-уведомления.
- **GET /status/{notification_id}** — получение статуса отправленного уведомления.
