Этот метод API позволяет разработчику программно отправлять email-уведомления пользователям. Метод принимает ID-шаблона письма и персональные данные для его заполнения, а возвращает индетификатор задачи в очереди на отправку.

### Структура запроса (Body)
| Поле | Тип | Обязательный | Описание | Пример |
|------|-----|--------------|----------|--------|
| `recipient` | string | ✅ Да | Адрес электронной почты получателя | `"user@example.com"` |
| `template_id` | string | ✅ Да | Идентификатор шаблона уведомления | `"welcome_email"` |
| `data` | object | ❌ Нет | Параметры для заполнения шаблона | `{"name": "Иван"}` |

**Пример запроса (JSON):**
```json
{
  "recipient": "user@example.com",
  "template_id": "welcome_email",
  "data": {
    "name": "Иван",
    "company": "IDnGO"
  }
}
```

### Структура успешного ответа (200 OK)
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Уникальный идентификатор отправленного сообщения |
| `status` | string | Текущий статус отправки (всегда `queued`) |

**Пример ответа:**
```json
{
  "id": "msg_123456789",
  "status": "queued"
}
```

### Коды ответа
| Код | Описание |
|-----|----------|
| **200** | Успешный запрос. Уведомление поставлено в очередь. |
| **400** | Некорректные данные запроса (например, неверный формат email). |
| **401** | Отсутствует или недействительный токен авторизации. |
| **404** | Шаблон с указанным `template_id` не найден. |
| **500** | Внутренняя ошибка сервера. Повторите запрос позже. |

### Возможные ошибки
| Код | Поле | Сообщение | Решение |
|-----|------|-----------|---------|
| 400 | `recipient` | "Invalid email format" | Проверьте правильность email-адреса. |
| 400 | `template_id` | "Field is required" | Укажите идентификатор шаблона. |
