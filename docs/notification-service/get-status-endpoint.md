# Получение статуса уведомления

## GET /status/{notification_id}

### Описание метода
Возвращает текущий статус отправленного уведомления по его уникальному идентификатору.

### Параметры запроса (Path)
| Параметр | Тип | Обязательный | Описание |
|----------|-----|--------------|----------|
| `notification_id` | string | ✅ Да | Идентификатор уведомления, полученный при отправке |

### Пример запроса (cURL)
```bash
curl -X GET https://api.notification-service.com/status/msg_123456789 \
  -H "Authorization: Bearer your_api_token"
```

### Структура успешного ответа (200 OK)
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | string | Идентификатор уведомления |
| `status` | string | Текущий статус: `queued`, `sent`, `delivered`, `failed` |
| `updated_at` | string | Время последнего обновления статуса (ISO 8601) |

**Пример ответа:**
```json
{
  "id": "msg_123456789",
  "status": "delivered",
  "updated_at": "2026-08-27T10:30:00Z"
}
```

### Коды ответа
| Код | Описание |
|-----|----------|
| **200** | Успешный запрос, статус получен. |
| **401** | Отсутствует или недействительный токен. |
| **404** | Уведомление с указанным ID не найдено. |
| **500** | Внутренняя ошибка сервера. |
