<span class="text-green">Зеленый результат проверки</span>
Пользователь не найден в запрещённых базах - можно <span class="text-green">одобрить</span>.<br>
<span class="text-red">Красный результат проверки</span> - пользователь найден в запрещённых базах.
 
Необходимо проверить совпадения, оценить риск-скоринг. Если есть сомнения наш ли пользователь, открываем отчёт через "Скачать результат AML":
- пользователь наш и найден в запрещённых базах - анкета <span class="text-red">блокируется</span> соответствующей кнопкой
- ложно-положительное совпадение/пользователь не найден в запрещённых базах - необходимо самостоятельно изменить на <span class="text-green">зеленый</span>, нажав на иконку карандаша рядом с результатом проверки, и <span class="text-green">одобрить</span> анкету.

!!! note ""
**Риск-скоринг** - автоматизированная оценка по совпадению с вышеперечисленными категориями на связь с незаконной деятельностью. В проверке выводится в скобках у найденных результатов. 
!!! note ""

Решение принимается на основе риск-скоринга и подтверждения данных. 

Если риск-скоринг:

- <span class="text-underline">от 60 и выше</span>: совпадение считается **подтверждённым** — отказываем соответствующей кнопкой. 
- <span class="text-underline">50-60</span>: ручная проверка — **необходимо изучить отчёт** ("Скачать результат AML"), после чего принять решение.
- <span class="text-underline">ниже 50</span>: проверка пройдена — **одобряем**, если в анкете нет других нарушений (в первое время рекомендуется дополнительно изучать отчёт, чтобы убедиться в отсутствии ошибок системы).

Отчёт представляет собой файл с большим массивом данных, внутри которого собрана вся общедоступная информация из разных источников по искомому пользователю. Данный отчёт открывается через Блокнот или браузер. При открытии через браузер можно "Автоформатировать" текст для более аккуратного отображения данных.
 
В самом отчёте нам нужно найти информацию (через **crtl + F**), которая относится именно к нашему пользователю, и убедиться, что указанные в записях данные содержат информацию о нарушениях.
 
Для быстрого поиска можно пользоваться ключевыми словами. **Например**: 

- ФИО и ДР проверяемого пользователя в разных формах
- PEP / Politically exposed person
- SIP / Special Interest Person
- Sanction / Sanction list
- и др.
