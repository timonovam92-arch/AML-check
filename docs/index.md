## Что такое AML?

**AML (Anti-money Laundering)** - это комплекс мер и процедур, направленных на борьбу с отмыванием денег и финансированием терроризма.

В нашей системе проверка пользователя происходит по двум основным параметрам:
- ФИО;
- дата рождения.

!!! note "Важно"
    В результате проверки может быть несколько строк по одному человеку. Это нормально, так как в разных источниках одни и те же данные могут быть записаны по-разному: с ошибками, сокращениями, в другом порядке или с использованием транслитерации.

**Система учитывает:**
 
- транслитерацию (разные стандарты перевода кириллицы на латиницу);
- фонетические совпадения;
- сокращения и аббревиатуры;
- возможные опечатки в источниках.
