# База знаний для службы поддержки

Раздел описывает способы решения различных технических проблем, которые возникают у пользователей.
Предназначен для специалистов службы поддержки.

## Ошибка 403 при отправке уведомления: 

**Для 1-й линии поддержки**
1. Попросите пользователя обновить страницу (F5).
2. Проверьте, активен ли его API-ключ в системе.
3. Если ошибка повторяется — передайте запрос на 2-ю линию с указанием времени и текста ошибки.

**Для 2-й линии поддержки**
1. Проверьте логи авторизации в Kibana по `request_id`.
2. Убедитесь, что у пользователя есть права на отправку уведомлений.
3. Проверьте актуальность сертификатов безопасности.
