На схеме представлен процесс обработки запроса в службе поддержки. Если решение есть в базе знаний — оно применяется сразу. Если нет — запрос эскалируется на второй уровень для углубленной диагностики.

```mermaid
flowchart TD
    A[Пользователь] --> B[Специалист L1]
    B --> C{Есть инструкция в базе знаний?}
    
    C -->|Да| D[Решение по инструкции]
    D --> E[Проблема решена]
    
    C -->|Нет| F[Эскалация на L2]
    F --> G[Анализ логов и метрик]
    
    G --> H{Проблема найдена?}
    H -->|Да| I[Решение]
    I --> J[Проблема решена]
    
    H -->|Нет| K[Передача на разработку]
    K --> L[Ожидание фикса]
```
